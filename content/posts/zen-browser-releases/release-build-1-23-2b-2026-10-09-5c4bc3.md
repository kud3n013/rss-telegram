## Zen Stable Release

### New Features

- Added an 'open library' command to the command palette.
- You can now right-click the media tab in the Library to disable it.

### Fixes

- Changed session backup file names to use local dates ([#15806](https://github.com/zen-browser/desktop/issues/15806))
- Fixed the library getting stuck after opening and closing it quickly ([#15833](https://github.com/zen-browser/desktop/issues/15833))
- Fixed blocked/unsafe downloads not having the choice to be opened or saved. ([#15809](https://github.com/zen-browser/desktop/issues/15809))
- Fixed moving multiple tabs to new window irrecoverably loses unloaded tabs. ([#15810](https://github.com/zen-browser/desktop/issues/15810))
- Fixed the sidebar having too much minimum width when they are aligned to the right. ([#15794](https://github.com/zen-browser/desktop/issues/15794))
- Fixed HEIC media being listed in the media tab but do not render correctly. ([#15778](https://github.com/zen-browser/desktop/issues/15778))
- Fixed space-assigned bookmarks not being saved anymore. ([#12721](https://github.com/zen-browser/desktop/issues/12721))
- Fixed a memory leak issue on startup.
- Other bug fixes and improvements.
