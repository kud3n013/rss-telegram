## Zen Stable Release

### Security

- <https://www.mozilla.org/security/advisories/mfsa2026-106>

### New Features

- Updated Firefox to 158.0
- Added a `--space <id|name>` option to the command line interface.
- Library will now show a 'Open in Folder' option and download speed when hovering over the toolbar icon.
- Zen now creates more accessible PDFs when saving a page as PDF, and when printing on Linux and macOS. This also fixes a variety of PDF rendering issues, such as missing math symbols.

### Fixes

- Fixed various animation, urlbar and UI performance issues.
- Fixed Library media tab requesting onedrive to download all files from cloud. ([#15888](https://github.com/zen-browser/desktop/issues/15888))
- Fixed unwanted label next to the search icon in urlbar. ([#14856](https://github.com/zen-browser/desktop/issues/14856))
- Fixed Avahi access so CUPS printers are listed in flatpak sandbox. ([#9651](https://github.com/zen-browser/desktop/issues/9651))
- Fixed various memory leak issues. ([#15954](https://github.com/zen-browser/desktop/issues/15954))
- Fixed a crash that could occur while Zen loaded website icons (favicons).
- Fixed menus such as List all tabs, Settings, etc being hard to read with a Windows High Contrast theme. Menu background and text colors now follow the Background and Text colors chosen for a custom contrast theme in Windows Settings.
- Other bug fixes and improvements.

### Changes

- Space routing regex will now match URLs as case-insensitive.
- Library's widget hover list will now only display recently downloaded files.
- Zen no longer rounds scroll positions to whole screen pixels. Scrolling is now smoother and more precise, especially on high-resolution displays or when a page is zoomed.
